## Where to start

- New to modding: `tModLoader-wiki/Basic-tModLoader-Modding-Guide.md`, then `Basic-Item.md`, `Basic-NPC.md`, `Basic-Projectile.md`.
- Art and sound: `tModLoader-wiki/Spriting.md`, `Assets.md`, `Basic-Sounds.md`, `Basic-glowmask-guide.md`.
- Looking up a class or method: find it in `class-index.md`, or search `tModLoader-API/source/`.
- Vanilla IDs and values: the `Vanilla-*.md` pages in the wiki.
